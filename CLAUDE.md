# Instrucciones del repositorio

Lee y aplica [AGENTS.md](AGENTS.md) antes de modificar este proyecto. Sus reglas se aplican también a Claude Code y a sus agentes delegados.

Las nuevas funcionalidades se implementan únicamente en el modo Normal, salvo que el prompt del usuario pida explícitamente implementarlas en Light. Esta restricción incluye las funcionalidades que podrían llegar a Light mediante código compartido.
